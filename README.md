# AI Skills

A collection of my custom skills for AI.

## Available Skills

| Skill | Description |
| --- | --- |
| [**assignment-automation-linux**](./assignment-automation-linux/) | Generates a Linux Bash automation script to execute assignment solutions, capture terminal output screenshots via `Xvfb`/`xterm`/`scrot`, and compile a LaTeX PDF report. |

## Usage

Load or copy the desired skill directory into your AI agent's skills path (e.g., `~/.gemini/skills/`, `.agents/skills/`, or your agent configuration) so it can reference the instructions in `SKILL.md`.
